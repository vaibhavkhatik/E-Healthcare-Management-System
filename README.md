## ⚙️ Technologies Used

- **Frontend**: HTML, CSS, JSP
- **Backend**: Java Servlets
- **Database**: MySQL
- **Tools**: Apache Tomcat, Eclipse IDE

---

## 🛠️ Setup Instructions

1. **Clone the Repository**
   ```bash
   git clone https://github.com/vaibhavkhatik/E-Healthcare-Management-System.git
   ```

2. **Import Project in Eclipse**
   - Go to `File > Import > Existing Projects into Workspace`.
   - Select the extracted folder.

3. **Setup Database**
   - Create a MySQL database (e.g., `healthcare_db`).
   - Import the `.sql` file (if provided) or manually create tables as per servlet code.

4. **Configure Connection**
   - Update your database credentials in the Java servlet files.

5. **Run on Server**
   - Right-click project → `Run on Server` (choose Apache Tomcat).
